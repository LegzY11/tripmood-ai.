# TripMood — онлайн-версия

TripMood помогает находить туристические места по интересам: красивые виды, необычные локации, ночная жизнь, еда, культура, природа и активный отдых.

## Архитектура
- Сайт: адаптивный HTML-интерфейс (`tripmood.html`).
- Backend: Python + FastAPI.
- AI: Gemini API выбирает категории поиска и отвечает в чате.
- Места: OpenStreetMap / Nominatim / Overpass.
- Хостинг: Render.

## Публикация
1. Создайте API-ключ в [Google AI Studio](https://aistudio.google.com/app/apikey).
2. Не добавляйте ключ в GitHub, HTML или README.
3. Войдите в [Render](https://render.com/) через GitHub.
4. Выберите **New → Blueprint** и подключите этот репозиторий. Render прочитает `render.yaml`.
5. В настройках сервиса откройте **Environment** и добавьте `GEMINI_API_KEY` со значением из AI Studio.
6. Дождитесь статуса **Live** и откройте выданный Render URL.

## Проверка
- Главная страница: URL сервиса.
- Состояние backend: `/api/health`.
- После настройки ключа поле `api_key_configured` должно быть `true`.

## Ограничения
Render Free может останавливать сервис после периода бездействия; первый запрос после простоя может быть медленным. У Gemini API и OpenStreetMap есть ограничения частоты запросов. Перед демонстрацией откройте сайт заранее и выполните пробный поиск.

## Безопасность
Ключ Gemini хранится только в переменных окружения Render. Не публикуйте его в репозитории и не отправляйте в чат.
